This tracker is separate from the product-foundation and future-roadmap tracker. It records improvements to features already implemented in the current DataTrust POC.

**Last updated:** 2026-11-03

## Where to find the auto-fix change

Open [`web/static/app.js`](./web/static/app.js) and find `renderAutofix()` (around line 355). The error text, retry button, and retry click handler are around lines 365-367.

This is a user-interface reliability improvement for the existing Impact-page proposal. It does not change how fixes are calculated or applied.
