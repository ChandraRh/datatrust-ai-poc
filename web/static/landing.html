How it works

From source file to a verified fix

Batch and streaming data flow through Bronze, Silver and Gold in PostgreSQL. DataTrust AI reads every layer and the audit trail.

  1. SourceCSV on Azure Data Lake or local, plus Kafka events every 30 s
  2. BronzeRaw data, kept as received
  3. SilverRules applied, duplicates removed, rejects kept for review
  4. GoldRevenue and settlement reconciliation views
  5. DataTrust AIDetect, investigate, explain, decide, verify

  2. 2Detect
  3. 3Investigate
  4. 4Explain
